# 比比看 Compara y Adivina

給西語母語、A2 以下學生練習中文比較句的遊戲：看人物圖，依比較句找出正確的人。

- `index.html`：遊戲引擎（出題、句型、計分、畫面），不含任何人物專用資料
- `themes/people.js`：**主題包**——人物資料、特徵定義（高矮、頭髮…）、分組與西語規則
- `teacher.js`：老師功能——自選出題範圍、分享連結、練習紙（列印／存成 PDF，可附答案頁）
- `calibrate.html`：特徵校正工具（讀同一份主題包）
- `img/P01.webp`–`P50.webp`：50 位人物（透明背景，臉／半身由程式裁切）

## 主題包

一個主題包是一支 `themes/<名稱>.js`，內容是 `window.THEME_PACK = {…}`：

| 欄位 | 用途 |
|---|---|
| `items` | 項目清單：`id`、`name`、圖寬高 `w`／`ih`、特徵值（0 = 不出題） |
| `dims` | 特徵定義：取值 `v`、門檻 `thr`／`near`、形容詞（中／拼音／西／英）、出現關卡 `lv`、權重 `w`、卡片裁圖 `crop` |
| `grp` | 解碼題、連鎖題只會把「同組」項目放在一起（人物 = 同性別） |
| `gnd`／`art` | 西語形容詞陰陽性、「最…」前的冠詞 |
| `dir`、`noun`、`t2s` | 圖片資料夾、選單裡的名詞（「2 個人」）、額外的簡體對照字 |
| `calib` | 校正工具的分頁 |

用 `?theme=<名稱>` 開啟對應主題（預設 `people`）。換主題只動主題包，不用改引擎。

**尚未抽出（做第二個主題前要處理）：** 題句裡的「誰／¿Quién」（換成水果要變「哪一個／¿Cuál」）、人名以外項目的西語冠詞與詞性、「得」字句（動作比較）。

## 老師管理中心的範圍碼 `?r=`

`?r=<範圍碼>` 會從中心專案的 `shared_bbk/{範圍碼}` 讀老師在「老師管理中心」存的範圍（不用登入），鎖定成「老師指定的練習」。可以加 `&class=<班級碼>` 回傳成績。找不到範圍碼時提示並退回一般模式。舊的 `?lv=…&d=…&t=…&n=…` 連結照常可用。

## 老師功能（teacher.js）

選單最下面的「老師設定」：選難度、要考的特徵、題型、題數，然後可以
- 用這個範圍玩一輪；
- 做練習紙（**訂閱**）：同一個出題器出題，排成 A4，按「列印」後選「另存為 PDF」；可附答案頁（含西語翻譯）；
- 複製分享連結：`?lv=2&d=height,age&t=pick,tf&n=10`，學生打開只會看到「開始練習」。

某個題型在目前勾選的特徵下湊不出題目時，會標 ⚠。自選範圍與分享連結免費；練習紙要訂閱。

## 班級與成績簿（classroom.js）

做法照跑吧！漢字（corre）：資料在中心專案 `subscription-48d3c`，Firebase SDK 只在需要時載入（一般學生不會載入）。

- **老師：** 選單最下面「班級成績簿（老師登入）」用 Google 登入，讀 `site_plans/{uid}` 判斷方案（月訂、年訂、試用）。
  - 班級（`teacher_classes/{uid}`、`classes/{cid}`）與跑吧、色數**共用**，最多 3 班；建班要訂閱中。
  - 打開班級：複製學生連結（一般模式，或帶上「老師設定」目前的範圍）、學生表（同暱稱不分大小寫與空白合併）、個人頁、常錯統計、匯出 CSV（每題一列）、刪除學生或清空本班的比比看紀錄。可篩選全部／最近 7 天／30 天。
  - 常錯統計：依句型（比、沒有…那麼、比…一點／很多、具體差距、更／還、跟…一樣、差不多、不一樣、誰比較、誰比、比誰、最）、特徵＋形容詞（例如「身高：矮」）、題型、對錯題的句子本身是對是錯；以「第一次就答對」由低到高排。
  - 訂閱到期：學生的新成績傳不進來；舊紀錄仍可看、匯出、刪除。
- **學生：** `?class=<班級碼>`（可再加 `&lv=…&d=…&t=…&n=…` 老師範圍）。先輸入暱稱（記在這台裝置），每玩完一回合寫一筆 `class_plays`。班級不存在或連不上時照常玩，只是不回傳。
- **每回合紀錄 `class_plays`：** `{cid, owner, game:'bbk', h(暱稱雜湊), nick, at, th(主題), lv, rg(範圍，''=一般模式), score, max, qs}`；`qs` 每題 `{t 題型, d 特徵, f 句型, p 方向 1/-1/0, ok 最後答對, f1 第一次就答對, ids 人物, tv 對錯題句子真假}`。引擎在出題時就把 `f`、`pol` 標在題目上（不影響出題結果）。
- **Firestore 規則：** 見 `firestore.rules.txt`，要貼到中心專案的規則裡（這個 repo 不會自動部署）。沒貼之前學生回傳會顯示「沒有權限」。
- **測試：** `node tests/test_classroom.js [截圖資料夾]`（Playwright＋`tests/firebase-mock.js` 模擬 Firebase，自帶伺服器）。
