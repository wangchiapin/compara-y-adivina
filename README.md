# 比比看 Compara y Adivina

給西語母語、A2 以下學生練習中文比較句的遊戲：看人物圖，依比較句找出正確的人。

- `index.html`：遊戲畫面（主選單、⚙️ 設定、作答、結果畫面）
- `engine.js`：**出題引擎**（出題、句型、拼音→注音、繁→簡）。遊戲和「老師管理中心」的學習單共用這一份，改這裡兩邊一起變
- `worksheet.js`：學習單（A4、可列印／存 PDF、可附答案頁），由老師管理中心載入
- `classroom.js`：學生端——班級連結（暱稱、成績回傳）、老師範圍碼 `?r=`
- `themes/people.js`：**主題包**——人物資料、特徵定義（高矮、頭髮…）、分組與西語規則
- `calibrate.html`：特徵校正工具（讀同一份主題包）
- `img/P01.webp`–`P50.webp`：50 位人物（透明背景，臉／半身由程式裁切）
- Firebase 規則：不放在這個 repo；正本在 game-kit（私人 repo）的 `firebase-rules/``subscription-48d3c.rules.txt`（含 `class_plays`）
- `og.jpg`：分享連結預覽縮圖（1200x630），貼到 LINE／WhatsApp 時顯示；名稱來自 `index.html` 的 `og:title`「比比看 · Compara y Adivina」（2026-10-28 加入）
- `tests/test_game.js`：自動測試（`node tests/test_game.js [截圖資料夾]`）

## ⚙️ 基本設定（三款遊戲共用）

右上角 ⚙️：字形（繁／簡）、語言（中＋西／中＋英／只有中文）、拼音／注音（拼音、注音、兩個都顯示、關）。比比看沒有語音，所以沒有語速。
設定存在 `localStorage` 的 `hanziGames.settings`（格式見 `corre/README.md`）；寫回時只改自己的欄位，保留語速 `rate`。第一次會從比比看舊的 `bbk_cfg` 搬過來。
拼音／注音顯示在題目、問句、選項按鈕、答完的說明句、小字典的每個詞上面（人名沒有）。

## 🚩 這題怪怪的（回報題目）

每題答完可按「🚩 這題怪怪的」回報（原因、留言），一般模式也能送；存到中心專案的 `bbk_reports`，只有 Ben 在分享區 `stats.html` 看得到。

## 結果畫面

分數 → 五級評語（依得分比例：0–39／40–59／60–79／80–99／100%）→ 過關提示（第 1／2／3 關各 80／75／70 分）→「✅ 成績已回傳給老師」（班級連結才有）→ 下一關（過關時）→ 再玩一次 → 主選單。

## 主題包

一個主題包是一支 `themes/<名稱>.js`，內容是 `window.THEME_PACK = {…}`：

| 欄位 | 用途 |
|---|---|
| `items` | 項目清單：`id`、`name`、圖寬高 `w`／`ih`、特徵值（0 = 不出題） |
| `dims` | 特徵定義：取值 `v`、門檻 `thr`／`near`、形容詞（中／拼音／西／英）、出現關卡 `lv`、權重 `w`、卡片裁圖 `crop` |
| `grp` | 解碼題、連鎖題只會把「同組」項目放在一起（人物 = 同性別） |
| `gnd`／`art` | 西語形容詞陰陽性、「最…」前的冠詞 |
| `dir`、`noun`、`t2s` | 圖片資料夾、選單裡的名詞（「2 個人」）、額外的簡體對照字 |
| `calib` | 校正工具的分頁 |

用 `?theme=<名稱>` 開啟對應主題（預設 `people`）。換主題只動主題包，不用改引擎。

**尚未抽出（做第二個主題前要處理）：** 題句裡的「誰／¿Quién」（換成水果要變「哪一個／¿Cuál」）、人名以外項目的西語冠詞與詞性、「得」字句（動作比較）。

## 老師管理中心的範圍碼 `?r=`

`?r=<範圍碼>` 會從中心專案的 `shared_bbk/{範圍碼}` 讀老師在「老師管理中心」存的範圍（不用登入），鎖定成「老師指定的練習」。可以加 `&class=<班級碼>` 回傳成績。找不到範圍碼時提示並退回一般模式。舊的 `?lv=…&d=…&t=…&n=…` 連結照常可用。

## 老師功能 → 老師管理中心

遊戲裡已經沒有老師區（5-4 起），主選單最下面是「老師管理中心」按鈕，連到 https://wangchiapin.github.io/profesor/#/home 。
出題範圍、練習連結、班級與成績簿、常錯統計、匯出 CSV、學習單都在中心。舊的分享連結 `?lv=…&d=…&t=…&n=…` 照常可用。

## 班級連結（classroom.js）

`?class=<班級碼>`（可再加 `&r=<範圍碼>` 或舊格式範圍）：學生輸入暱稱，每玩完一回合把每題作答寫進中心專案的 `class_plays`（`game:'bbk'`；步驟 6-2 起多記範圍碼 `r`，中心成績冊依範圍分開顯示）。老師的訂閱到期時傳不進去，但學生照樣可以玩。Firebase SDK 只在需要時載入。

## 手機瀏覽器備註：捲動後回不到頂端（2026-10-24）
iPhone 版 Chrome 上，頁面可以捲動時，往下捲之後有時回不到最上面（Safari 正常）。
處理方式（已套用在本遊戲）：
- `<meta name="viewport">` 設 `maximum-scale=1`，不使用 `viewport-fit=cover`。
- `<html>` 加 `html{color-scheme:light}`。

兩項一起改後，手機 Chrome 測試恢復正常；尚未分開測是哪一項有效。新增頁面請照這個寫。

- 只有一個開關：老師管理中心（分享區 `stats.html` 的「老師管理中心遊戲開關」，`portalStatus/center-bbk`，`off:true`＝維修中）。
